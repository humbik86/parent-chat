# Parent Chat
Простой одностраничный сайт о правилах поведения в родительских чатах.
## О проекте
- Страница сделана на `HTML`, `CSS`, `JavaScript`
- Тема: серый дизайн + glassmorphism
- Есть анимации, интерактивные карточки и мини-тест
## Файлы
- `index.html` — структура страницы
- `styles.css` — стили и адаптивность
- `script.js` — поведение, анимации, тест
- `README.md` — эта инструкция
